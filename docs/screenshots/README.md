# README showcase captures

These four images are product-facing documentation assets, not verification or
provenance evidence. They let the repository show the current Nocturne
instrument without adding personal settings, Radio files, or network data.

They were captured from the `nocturne` full profile at
`v0.1.0-alpha.13-dev · visual-appearance-dev` with the deterministic browser
smoke harness. The three room views use a 1440 × 1000 viewport; the appearance
image is the isolated Room settings section. Weather, location, and Radio names
are local sample fixtures, and playback is not started.

- `onsen-rain-lantern.webp` uses the packaged rain fallback in Rain Lantern.
- `sky-observing.webp` uses fresh sample weather after the stale-state check.
- `radio-bedside-deck.webp` shows the first sample track selected but idle.
- `appearance-room.png` shows Moonwater, Clear type, and Clear lighting selected.

The room screenshots are WebP exports at quality 88. Keep README assets small,
visually inspect them after every refresh, and never substitute captures from a
personal runtime. Generated `verification-artifacts/` remain transient and do
not belong in the product tree.
