# Hardware reports

These are community observations, not universal guarantees. Nocturne does not
collect hardware information automatically.

| Device | RAM | Usage | Edition | Result | Source/date |
|---|---:|---|---|---|---|
| Raspberry Pi 5 | 8 GB | Local display | Nocturne | Owner test pending | — |
| Raspberry Pi 4 | — | Local display | Nocturne | Reports wanted | — |
| Raspberry Pi 3 B+ | 1 GB | Local display | Nocturne Pi | Reports wanted; design target only | — |
| Raspberry Pi 3 B+ | 1 GB | Server only | Nocturne Pi | Reports wanted; design target only | — |

A useful report includes the model and RAM, operating system, browser, edition,
whether the host also displayed the page, what happened, and how long it ran.
Plain-language reports are welcome.
