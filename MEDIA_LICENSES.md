# Media licenses and provenance

Nocturne can use three kinds of local media:

1. **Procedural starter beds** created locally by `scripts/generate_noise.py` during install.
2. **Curated CC0 Core Sound Pack loops** placed in `sounds/library/` and listed in `sounds/sound_library.json`.
3. **Legacy optional Pixabay files** for older fixed ambience filenames in `sounds/`.

For public alpha releases, prefer path #2 plus the generated procedural fallback. Do not rely on the legacy Pixabay scraper for the first-run experience.

## Procedural starter beds

```bash
python scripts/generate_noise.py
```

This creates the local/generated procedural beds. Original set:

- `sounds/soft-rain-noise.wav`
- `sounds/window-rain-noise.wav`
- `sounds/heavy-rain-noise.wav`
- `sounds/distant-storm-noise.wav`
- `sounds/soft-wind-noise.wav`
- `sounds/pinknoise.wav`
- `sounds/brown-noise.wav`
- `sounds/white-noise.wav`

Expanded set (alpha.7):

- `sounds/low-rumble-bed.wav`
- `sounds/distant-train-bed.wav`
- `sounds/soft-traffic-bed.wav`
- `sounds/fan-room-bed.wav`
- `sounds/rain-on-glass-noise.wav`
- `sounds/deep-water-bed.wav`
- `sounds/ember-crackle-bed.wav`
- `sounds/distant-thunder-bed.wav`
- `sounds/soft-thunderstorm-bed.wav`

These files are generated by Nocturne itself with deterministic seeded NumPy
synthesis and are not Freesound/CC0 downloads. They exist so the app is usable
immediately after install. Each is named honestly as a synthetic texture bed,
never as a field recording. The two thunder beds are alpha.8 audition
candidates and are not default slots.

## Curated CC0 Core Sound Pack

Finished CC0/user-owned loops live in:

```text
sounds/library/
```

They are described in:

```text
sounds/sound_library.json
AUDIO_CREDITS.md
AUDIO_PROVENANCE.md
```

For each bundled third-party sound, keep:

- source site and exact source URL
- creator/uploader name
- license and license URL
- download date or verification date
- screenshot showing the title, creator, and license
- original and processed filenames
- SHA-256 hash after final processing
- notes about edits, normalization, transcoding, metadata stripping, trimming, or loop checks

The alpha.7 Core Sound Pack is intended to include only Freesound sounds verified as Creative Commons 0. CC0 does not require attribution, but Nocturne credits sources anyway.

## Legacy optional Pixabay workflow

The older fixed ambience filenames are still supported for compatibility and by `scripts/fetch_media.py`:

```text
calming_rain.mp3
gentle_rain.mp3
heavy_rain.mp3
rainstorm.mp3
heavy_storm.mp3
thunder.mp3
fireplace.mp3
pinknoise.wav
```

This path is deprecated for public alpha releases. `media_sources.default.json` intentionally contains placeholder URLs and exists only as a legacy reference. The preferred release path is the bundled/generated Core Sound Pack.
