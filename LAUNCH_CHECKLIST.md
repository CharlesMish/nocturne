# Launch checklist

1. Run the installer for this platform, or prepare `.venv` manually.
2. Start with `python run_nocturne.py` and open the printed localhost URL.
3. Raise one channel and confirm audio begins after the gesture.
4. Try **silence all**, then **resume mix**.
5. Save, alter, and re-apply one local scene.
6. Open Settings → Device integration and record which capabilities are shown.
7. For LAN testing, launch with `--host 0.0.0.0`; compare plain HTTP with a
   certificate the test device trusts when available.
8. Complete `docs/FIELD_TEST_CARD.md` before calling a sound comfortable or a
   device path dependable.

Nocturne alpha is not the only alarm for an overnight test.
