# Changelog

## 0.1.0-alpha.12-dev — dual-profile hardening

- Added the shared Nocturne and Nocturne Pi presentation profiles while keeping
  one runtime and one product codebase.
- Hardened product and evidence packaging against local settings, personal
  Radio tracks, scratch media, old archives, and undeclared intake files.
- Preserved quarantine boundary guides through ordinary Git staging and made
  their presence part of the release audit.
- Made settings writes atomic, added safe environment fallbacks, and documented
  the unauthenticated trusted-LAN boundary.
- Kept Raspberry Pi, browser background, accessibility, listening-comfort, and
  overnight behavior explicitly field-test pending.

## 0.1.0-alpha.11 — field-readiness polish

- Added a concise device/browser results matrix while keeping platform support
  explicitly field-test pending.
- Versioned local scene records, preserved alpha.10 scenes as schema 1, capped
  serialized scene storage, and clarified blocked/full-storage failures.
- Added a direct product-side pointer to the detached rain-video transform
  record and its exact packaged hash.
- Kept the product/evidence split and avoided new runtime systems or feature
  claims.

## 0.1.0-alpha.10 — product pass

- Added browser-local named scenes for mixer and Radio state.
- Added feature-detected Media Session metadata/actions and return-from-background
  interruption messaging.
- Added a web-app manifest and local install icons without adding a service
  worker or claiming offline/overnight reliability.
- Added optional trusted-certificate launch arguments.
- Added an offline cyclic crossfade loop baker with hashes, parameters, safety
  boundaries, and `audition_required` sidecars.
- Rendered one seam-repair candidate and kept it quarantined.
- Reduced the rain video from 13.3 MB to 2.9 MB while retaining the original and
  transform record in the evidence bundle.
- Split tester-facing release material from history, screenshots, logs,
  verification evidence, and non-public quarantine payloads.
- Expanded runtime/browser/release checks around the new behavior.
