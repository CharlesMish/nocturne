# Seam-baked audition candidates

Files here are **not public catalog sounds**. They were rendered by
`scripts/bake_seamless_loop.py`, retain a JSON transform sidecar, and remain
inside the server-denied `sounds/inbox/` tree until a human listening pass.

A low numerical boundary jump is only a screening result. Promotion requires
headphones, a phone/tablet speaker, and the intended bedside speaker, with the
loop boundary heard repeatedly in context.
